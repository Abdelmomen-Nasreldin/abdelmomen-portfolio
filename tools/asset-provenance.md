# Portfolio image provenance

Captured September 6–7, 2026 from isolated local demonstrations of the actual applications.

- `cafe-order.webp`: native Tauri order-entry workspace, with an unsaved two-item demonstration cart.
- `cafe-orders.webp`: native Tauri pending-order list with fictional guests and transactions.
- `dental-appointments.webp`: Arabic scheduling interface with four fictional patients.
- `dental-chart.webp`: English patient record and dental chart for a fictional patient.

The café demonstration used a separate application identifier and fresh local database. The clinic demonstration used a separate runtime directory, fictional patients, and development accounts. No customer database was copied for these captures. Images are compressed WebP conversions of the reviewed interface captures. Figures are labelled as demonstrations in the portfolio; they do not establish production-readiness or measured business impact.

`social-preview.svg` is the editable source for the 1200 × 630 social preview PNG, using the same professional title as the site.

`public/icon.svg` is the editable vector source for the `AN` portfolio mark. PNG exports are provided at 32, 180, and 512 pixels for browser tabs, Apple home screens, and the web manifest.
